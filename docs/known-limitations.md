# Known Limitations

These boundaries are intentional for the assessment MVP:

- Compliance documents are mock metadata only.
- Tracking is simulated.
- Matching uses city or area values instead of real distance calculations.
- There is no real GPS integration.
- There is no payment gateway.
- There is no email, SMS or OTP integration.
- There are no production electronic signatures.
- There is no AI or machine learning.
- There is no advanced route optimisation.
- There is no frontend.
- There is no production cloud deployment.
- All data is synthetic.

Implementation-specific limitations and technical debt will be added as they become known.
