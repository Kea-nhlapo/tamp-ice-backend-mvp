# Planned Demonstration Guide

> **Planning notice:** This sequence must be updated after implementation to match the real Swagger paths, payloads, credentials and observed responses.

1. Open Swagger.
2. Register or log in as a Freight Owner.
3. Create a cargo load.
4. Register or log in as a Transporter.
5. Create an available truck.
6. Generate matches for the load.
7. Explain why the truck qualifies using the returned reasons.
8. Accept the match.
9. Retrieve the digital receipt.
10. Advance the mock tracking status.
11. Complete the trip and submit a rating.
12. Log in as an Administrator.
13. View users, compliance metadata, dispute information, audit events and metrics.

Use synthetic demonstration data only. Do not imply a step works until it has been implemented and rehearsed.
